ня-API

эндпоинты

GET /api/nya

случайное мяу-число и кошкодевочка. опционально ?min=1&max=100 (границы ±1000000, размах не больше 1000000).

curl nyaaa.moe/api/nya

{
  "nya": 7,
  "catgirl": "Чокола",
  "kaomoji": "(=^･ω･^=)",
  "emoji": "🍫",
  "mood": "мурчащая"
}

GET /api/quote

мудрость случайной кошкодевочки из Nekopara. 18 цитат, все в характере.

curl nyaaa.moe/api/quote

{
  "quote": "жизнь без сладкого - это просто длинный сон наяву, ня!",
  "author": "Чокола",
  "from": "Nekopara"
}
