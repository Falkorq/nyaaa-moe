# Сертификаты и «няшки сайта»

После 10 шагов в `guide.html` посетитель вводит ник. Прогресс сохраняется на сервере в отдельной сессии: браузер отправляет каждую отметку, а время записи ставит сервер. Сессии живут 30 дней; просроченные удаляются при первом обращении, фоновой чистки у Blobs нет - заброшенные сессии исчезают сами по истечении срока. `POST /api/certificates` принимает ID завершённой сессии и выдаёт сертификат в Netlify Blobs (`nyaaa-certificates`). Сертификат появляется на `nyashki.html` и доступен по ссылке `certificate.html?id=...`. Список галереи кешируется на 30 секунд, чтобы каждый `GET?page=` не сканировал весь стор. Серверная запись подтверждает отметки в приложении, но не физическое выполнение игровых действий. Это игровая выдача, а не подтверждение личности.

## Развёртывание

Netlify устанавливает зависимость `@netlify/blobs` из `package.json`, выполняет `npm run build` и публикует только `dist/`. Функции из `netlify/functions/` работают отдельно. `npm run build` собирает статические страницы; `npm test` проверяет выдачу, чтение, список и удаление сертификатов на тестовом хранилище. Для локального просмотра после сборки запустите `npm run dev`: сертификаты в нём хранятся только в памяти до остановки процесса.

Netlify Blobs привязан к сайту: записи сохраняются между деплоями. На другом хостинге API нужно подключить к другому хранилищу.

## Управление списком

Публичная форма без аккаунтов: любой может вписать ник. Ник ограничен 2–24 символами, ссылки и HTML не принимаются; функция Netlify ограничена 20 запросами в минуту с одного IP. Это снижает случайный спам, но не заменяет модерацию.

Для удаления нежелательной записи задайте секрет `CERT_ADMIN_TOKEN` в переменных окружения Netlify и отправьте `DELETE /api/certificates/{id}` с заголовком `Authorization: Bearer <секрет>`. ID виден в ссылке на сертификат. Удаление недоступно, если секрет не задан. После удаления запись может оставаться в некоторых региональных кешах до 60 секунд из-за модели согласованности Netlify Blobs.

Ник опубликован сразу после отправки формы. Пользователь предупреждён об этом рядом с полем. Если нужен предварительный просмотр перед публикацией, добавьте модерацию до запуска функции на публичном сайте.
